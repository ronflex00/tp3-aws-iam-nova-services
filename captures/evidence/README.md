# Captures de preuve

Déposer ici uniquement des captures expurgées de secrets. Ne jamais capturer
une clé IAM, un QR code MFA, un CSV de credentials ou un token STS.

Le retest du scénario `Bucket policy + TPDenyRead` a été consigné dans
`docs/tests.md` à partir des codes de retour uniquement. Aucun screenshot ni
fichier brut de sortie contenant des identifiants n'a été conservé.

`pre-cleanup-inventory.md` conserve l'inventaire expurgé réalisé avant les
suppression AWS. `docs/cleanup.md` consigne les confirmations de suppression.
Aucune clé d'accès, valeur de secret, token STS ou Account ID n'est enregistré.
